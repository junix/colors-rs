## 先看哪一张

先看 `chromap-explainer/`。它是现行交付：色环互补色 ≠ 可读前景色，数字来自冻结证据，页面本身不带代码坐标。入口是该目录的 `index.html` 与 `README.md`。

只有需要静态架构总览、且能接受代码标识符上台时，才打开旧页。旧页把标识符画上台不是开工重画的许可；要修，另开任务。
